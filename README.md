# ni88fury_bot
A simple and free cross platform bot that can manage youtube live chats, create custom overlays for obs, custom commands, known viewers, custom welcoming methods and a lot more. i am building this out of frustration out of lack of quality streamer bots for mac os platform. completely build using python and can be ported to any platform.
